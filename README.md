# Financial Process Automation (Python + SQL)

A small portfolio of finance-automation scripts that mirror day-to-day
SAP FI/CO consultant and business-analyst work: reconciling sub-ledgers to
the GL, validating a month-end close, and flagging budget variances —
built with Python, pandas, and SQL (SQLite).

This repo exists to demonstrate the kind of automation work behind bullets
like *"Drove reconciliation process improvements, reducing cycle time by
18%"* and *"Streamline portfolio reporting workflows through SQL-driven data
pipelines"* with runnable code instead of just a resume line.

## Why these three projects

| Project | Resume connection |
|---|---|
| [`01_ap_ar_reconciliation`](./01_ap_ar_reconciliation) | AP/AR sub-ledger to GL reconciliation, reducing discrepancies and cycle time |
| [`02_month_end_close`](./02_month_end_close) | Close-readiness validation, GL account mapping, financial controls |
| [`03_variance_detection`](./03_variance_detection) | Budget vs. actual variance detection, cost/profit center reporting |

Each folder is self-contained: its own script, its own README explaining the
business problem, and a `sample_output/` folder with real output so a
reviewer can see results without cloning and running anything.

## Data

Everything runs against **fully synthetic** data generated by
[`data/generate_data.py`](./data/generate_data.py) — a mock chart of
accounts, cost/profit centers, AP/AR sub-ledgers, GL transactions, and a
budget/actuals table, shaped like what you'd pull from an SAP FI/CO extract.
The generator seeds a handful of intentional discrepancies (unposted
invoices, mismatched amounts, suspense entries, bad account mappings, budget
overruns) so each script has something real to catch — this is not real
company or client data.

## Quickstart

```bash
git clone <your-repo-url>
cd financial-process-automation
pip install -r requirements.txt

# 1. Generate the synthetic dataset (run once)
python data/generate_data.py

# 2. Run each automation
python 01_ap_ar_reconciliation/reconcile.py
python 02_month_end_close/close_checklist.py
python 03_variance_detection/variance_detection.py
```

Each script also accepts `--data-dir` and `--output-dir` flags if you want
to point it at a different dataset or write results elsewhere — see each
sub-project's README for details.
